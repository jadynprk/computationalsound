what's this?

this is an implementation of a 2D Game of Life cellular automaton mapped to music. each column represents a pitch class like "A", and each row represents an octave. when a cell is born, its corresponding note is triggered. a cell is born if it has exactly 2 live neighbors, survives if it has 2 or 3 neighbors, and dies otherwise.

design

pitch mapping

the columns of the grid cycle through the C pentatonic scale (C, D, E, G, A). i chose a pentatonic scale because they're generally more forgiving and playing lots of notes doesn't clash badly. the rows map to octaves, so the top of the grid is higher-pitched and the bottom is lower. as a result, each cell represents a specific note.

triggering notes

notes are triggered when a cell is born. at first, i tried to play every live cell in a generation, but that sounded pretty bad and wasn't very good at showing the evolution of the grid. to do this, we compare the current grid to the next one before advancing. when the grid dies, we automatically reseed to keep going. you can turn this off by by unchecking the "Loop" box.

visuals

newborn cells are white. after that, they fade from light pink to dark red as they age.

audio

the audio took a good amount of fiddling with to get the right sound. i turned the volume down overall so that many simultaneous births wouldn't clip. i also messed with the adsr levels, especially so it would sound good at high bpms. the biggest lesson i learned with this project was there are a surprising amount of tradeoffs to calculate when working with audio, like when to cap polyphony.
